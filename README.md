
# Canteen Management System

A simple Java project for managing canteen operations like menu handling, order management, and billing.

## Features
- Add food items
- View menu
- Place order
- Manage canteen records
- Orders History 

## Technologies Used
- Java
- spring boot
- JPA
- MySQL
